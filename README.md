# Travailler en binôme sur GitLab avec un workflow Git simple

Un lab complet à faire à deux, ou seul en jouant les deux rôles : créer un projet GitLab, inviter son binôme, protéger `main` et `develop`, se faire refuser un push, passer par une merge request, résoudre un conflit, publier une version et corriger la production avec un hotfix.

Il se suit sur [byte-layers.com](https://byte-layers.com/fr/labs/gitlab-pair-workflow) ou dans VS Code avec l'extension [byte_layers](https://marketplace.visualstudio.com/items?itemName=byte-layers.byte-layers). Le contenu est dans `.layers/`.

**Prérequis :** savoir faire un commit, créer et fusionner une branche, et utiliser `git push` et `git pull`. Il faut Git 2.28 ou plus récent, un compte gratuit sur gitlab.com pour chaque personne, et un terminal (Git Bash sous Windows).
